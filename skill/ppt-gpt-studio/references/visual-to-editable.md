# 构图保真与可编辑交付

## 从好看的整页图提取布局

生成整页视觉稿时，一页保持一个主视觉。提示词交代标题起点、图文相对位置、主图比例、留白和阅读顺序。用完整的确认文案填充说明区，独立插画保持无字，并给标注和连接线留出空间。事实、数字和引文始终回到用户确认的文本及数据。跨页沿用已选样张的色彩与层级，构图按内容变化。

重建时先定主图边界、标题基线、文本区、间隔、对齐和背景色。Studio 会在编译前用纯 Pillow（无需安装 OCR）自动提取 `visual_anchors`（底色、`title_box`、底部浅色结论条 `bottom_bar` 与竖分割线 `dividers`）作为实测像素参考，模型应优先对齐这些坐标与色值，避免盲估导致版面偏散或字重发虚。用实际画布像素记录原生对象的 x/y/w/h、字号和颜色。图片构图与模板不一致时，允许跨栏调整对象的位置、宽高和换行。保留已经确认的中文、单位、引用、数据和含义。选中图里没有的模板装饰可以省略。

- **行内富文本层级（`runs`）**：同一文本框内需保留“粗体小标题 + 常规正文”或局部高亮时，可在 `objects` 或 `parts` 中返回 `runs:[{text,bold,color,size}]`，导出为原生 PowerPoint 多 run 段落，同时严格校验拼接后与已确认文案逐字一致。
- **原生底框与分割线（`fill` / `rules`）**：当原图结论条、卡片或标签带背景色块时，可给 `text` 对象附 `fill`、`corner_radius`、`stroke`、`stroke_width` 还原原生圆角底框；原图中的细竖线/横分割线可通过顶层 `rules:[{x,y,w,h,color}]` 原生还原。

| 页面或元素 | 重建方式 | 目标 |
|---|---|---|
| 封面和章节页 | 主插画裁成独立可移动图片，标题及署名为文本框 | 保留成图的主视觉、图文比例和留白 |
| 复杂机制图 | 保留不需修改的插画，按需要用原生标签和连接线标记；分叉和并列关系使用已确认的节点和原生连接线 | 允许编辑语义层，同时保住绘图质感 |
| 简单流程 | 节点、文字和连接线直接用 PowerPoint 对象 | 移动节点后可以继续调整关系 |
| 统计图和表格 | 由核对过的数据重建；要求编辑数据时使用带数据表的原生图表 | 数字准确，后续能换数据 |
| 原始证据图、Logo 和现场照片 | 使用经过授权的原件 | 保持出处和证据完整 |

裁剪前检查图像轮廓、背景边缘、内部文字和箭头。裁剪框与可编辑文字必须分开，避免重影与白底接缝。如果插画和文字已经融合，优先沿用获准构图重新生成无字素材，或用原始图替换并重新预览。复杂机制的节点与路径需要编辑时，通过原生形状和连接线重建并检验关系。当前工作台支持线性流程、带原生节点的分叉与并列关系和柱状图。关系图须在逐页方案中确认节点 labels 与以 0 为起点的 links；排版模型按原图提取节点的位置、尺寸、对齐、换行、字号、填色、描边、顺序号及连线线宽和颜色。节点文案和连线关系仍来自已确认的数据。若排版失败，保留已通过页面和本页的原始生图，再修正本页的布局。保留整页位图的版本应标为图片版。

## 判断模型是否够用

- **画图模型**看构图、画风一致性、主图完整性和指定区域留白。用同一份代表页指令比较模型输出，允许使用已批准的风格样张作参考。
- **看图和排版模型**看能否识别主图、留白和阅读层级，给出有效裁剪范围与版面坐标。结果常越界或压字时，缩小自动化范围，改用锁定的版面区域和无字独立素材。
- **输出程序**负责原生文字、字体、嵌入数据、比例、连接线和保存校验。模型不负责猜数字，也不能以描述代替原生对象。

每个代表页比较主图范围、图文关系、背景接缝、文本换行、引文和结构。渲染实际样张 PPTX，检查标签、说明、引线与节点是否为独立对象。工作台缩略图由场景数据生成，字体和画面以打开 PowerPoint 导出物为准。图片 PPT 和可编辑 PPT 共享同一套确认后的场景。只改页内内容时优先重审该页和受影响的相邻页。

## 带部件标注的插画

一页包含中央设备图、两侧部件名与功能、页底流程时，分别建立主图裁剪、原生标签、说明、指示线及流程节点。根据主图中部件的位置排两侧文字，标题和说明各有层级。页底流程用已确认的节点和连接方向。

- 在编译器返回的 `objects` 中，原稿的一行正文可改为 `{index, parts:[{text,x,y,w,h,size,color,bold}, …]}`。每个 part 是独立文本框，数组按确认稿的字序和标点排列，坐标按版式自由放置。需要继承换行时可给每项 `lines`，核对行拼接后与该项文案一致。
- `callouts` 每项为 `{index,part,points,color,width}`。`index` 对应原稿对象，`part` 从 0 起算，`points` 按引线顺序提供两到五个画布像素坐标。起点靠近标签侧边，终点在独立插画内并生成一个原生定位点。不能辨认部件时先核对原件。
- 导出前逐条核对标签和落点，检查引线是否经过其他文字，流程是否仍能按预定方向读取。主图可单独替换，部件名、说明、各段引线和定位点可分别修改。


## 关系图页的逐页配置例

    "art_mode": "diagram",
    "diagram": {"labels":["读取状态","已完成","未完成"],"links":[[0,1],[0,2]]}

该页整页视觉稿可出现这三个标签和两条箭头。原生编译保留已确认节点关系，用 diagram_boxes 返回各节点的位置、宽高和样式。lines 可保留原图断行，拼接后与已确认标签一致。按图片提取 align、valign、pad_x/pad_y、bold、stroke/stroke_width、corner_radius 和顺序号 number（如 01）。连线样式 diagram_edges 按已确认的 links 排列，包含 index、color 和 width。编号、节点及连线在 PowerPoint 中分别可编辑。没有需要保留的局部插画时 crops 使用 []。
