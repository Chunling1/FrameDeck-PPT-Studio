# 科研汇报构图参考

本参考提炼自用户提供的《科研项目答辩 PPT 格式与构图拆解手册》。两套申报案例的截图用于理解信息结构。文件中的主题、数字、人物、机构标识和原图不作为新项目的证据或素材。以下比例是构图起点，随画幅、标题长度和证据可读性调整。

## 先确定一页要回答的问题

把每一页写成一张内容卡，记录评审问题、现有证据支持的判断、主证据、辅助证据、阅读顺序和需要时的页尾落点。项目论证可沿「需求与缺口 → 科学问题 → 任务与方法 → 验证 → 资源、交付与风险」展开。个人考评可沿「研究方向 → 已有成果及本人贡献 → 当前基础与缺口 → 后续验证」展开。研究现象、假设、已验证结论、计划交付分别用能辨认的措辞。

## 按关系选构图

| 评审需判断的关系 | 构图起点 | 画面中最重要的东西 |
| --- | --- | --- |
| 需求与差距、现象与科学问题 | 并置两个可对读的区域；一边资料密时采用约 40∶60 或 2∶1 的宽窄区 | 左边放代表性现象或现状证据，右边放差距或待检验机制。标题、图注和比较条件对齐 |
| 方法如何支撑结果 | 窄方法栏配宽证据栏，约 1∶2 | 方法栏交代输入、方法与条件，证据栏放主对照。模型与实验确有反馈时才画返回线 |
| 任务依赖、系统如何工作 | 左输入、中部主系统、右输出或验证；主系统占正文近半，图形间留连接区 | 先看中心系统和边界，再沿真实数据流或物理流读到验证端。每条箭头写清起点、终点和传递对象 |
| 系统有两个互补子链 | 中央放系统，两侧沿同样高度解释各自职责 | 中心图说清整体，各侧各配一份能说明职责的局部证据。环形构图须有真实闭环关系 |
| 多项贡献有明显主次 | 左一大块、右侧上下两块，大块约占正文 40%–50% | 主贡献独占大块，右上讲方法或产物，右下讲变量、指标或验证。三块保持共同起点和层级 |
| 已经监测什么、手里有什么数据 | 一张代表性现场或装置图为主；另一侧汇总已核实范围、数据类别和可开展的分析 | 按「对象 → 测点或来源 → 产物」对应照片和数据。群体项目规模、个人工作和可直接使用的数据范围分开交代 |
| 阶段推进与可验收交付 | 共用时间轴，节点下是同构等宽列；每列按任务、证据或产物、验收顺序 | 日期、任务、交付各自对齐，真实依赖置于阶段交界；计划动作清楚标为拟开展 |
| 人员、资源、结果凭证或风险 | 同字段并列，或上层指标下层原件；同类风险可用同构网格 | 身份、责任、产物与设备能力一一对应。风险等级有文字；原件露出可追溯字段 |

## 先分配面积，再定装饰

- 科研内容页可从左右版边各 4%、栏缝约 2% 起排。全稿复用题名起点、导语基线和证据区底线，同构页复用栏宽和图注位置。
- 页眉只承担定位。导语用一句话给出可核实的判断或待验证的问题。确有第二层信息时，第二句交代研究动作。页尾只在有独立结论或交付时出现。
- 主视觉承担本页最重要的证据或关系，可以是一组同尺度对照。资料较密时，先归并为两到三个一级区；必须投影读取的轴、单位和工况优先获得面积。评价版面时看视觉焦点和阅读路径，可随证据密度调整留白。
- 同级对象共享基线。优先用间隔、字号和明度做分组，少量强调色标关键变量、差异或状态。保留用户所选色板。来源材料中的色相、机构标识和装饰结构仅在用户指定时采用。

## 证据与可编辑边界

原件用作证据时，保留可核验的图例、坐标、单位、工况、日期、作者或来源。用原始数据重建图表，保住真实对照条件。只在来源给出比较对象和条件时写提升率。概念插画、真实照片、实验结果和计划指标分别命名；监测覆盖支持数据基础，不能单凭覆盖推出机制或效果。

编制关系图前先确认标签和方向。原生页适合直接放授权图件或已核实的数据图；插画页把原件安放和可编辑信息写在构图中，让图像模型绘制能单独裁切的概念主体。现有制作方式不能容纳必要证据时，在逐页方案说明并交由用户选择。

## 单页示例

主题为「空气源热泵监测数据的整理与校验」，处于资料整理阶段。上方左对齐标题和一句导语。正文用左 35%、右 65% 的宽窄区。左侧交代已核实的数据来源、测量变量和记录条件；右侧优先展示一份供稿中的代表性序列，下面按需给出时间对齐、缺失标记与工况初分的简洁路径，具体步骤以确认稿为准。真实曲线按原件或真实数据落版。没有曲线原件时，为它保留位置或用注明身份的机制示意表达数据关系。页尾可交代下一步验证安排。
