# 生图提示词写法

整页视觉稿由 GPT 或 Gemini 图像模型绘制。这类模型擅长理解「画面是什么样」，不理解流程、工程和审核规则，也看不到其他页面。因此 Studio 把内容卡分成两层：

| 层 | 字段 | 读者 |
|---|---|---|
| 策划层 | question、candidate_a/b、choice、sequence、treatment、handoff、boundary | 策划模型、校核模型、可编辑重建 |
| 画面层 | medium、layout、art，以及确认稿中的标题、结论、说明与关系图节点 | 画图模型 |

## 编译后的五段

1. **用途与画法**：画幅、风格预设和 medium。
2. **版面**：layout，用相对比例说明对齐、分组、层级及阅读顺序。
3. **主视觉**：art，并附一句创作授权：在主视觉区域内可以自由选择造型、质感、光影和细节，只要对象、关系和方向不变。
4. **画面文字**：由确认稿自动生成。标题、结论、说明和关系图节点加引号，按 layout 分配到相应位置。部件名与说明可分行。关系图连线写成「“A”指向“B”」。文案太长时先在逐页方案压缩并确认。
5. **配色与整体要求**：颜色名加色号，标明各颜色的用途，再接公共指令。

样张确认后，后续页面附带已确认样张作为参考图，并加一句说明：沿用参考图的配色比例、线条粗细、字体气质、留白节奏和质感，内容按本页描述重新绘制。

## medium、layout、art 的写法

- **medium（审美来源）**：写插画类型、线条与笔触、材质、光线和整体气质。可借用「像某类出版物或设计语言」的说法，例如扁平编辑式信息插画、细线技术插图、等距线框、纸艺拼贴、柔光三维黏土。全稿保持一致。
- **layout**：说明选定的构图，包括主图比例、标题起点、图文对应、字号和字重、各组的对齐关系及阅读路线。说明哪几组文字在两侧或页底，避免画出没有文字的标签框。
- **art**：连贯叙述主体、隐喻、视角、空间关系、运动方向、视觉焦点与细节。复杂画面可按「先背景、再中景、最后焦点」分步写。

三项共同要求：

- 用肯定句描述想要的画面，例如用「纯平面色块，没有明暗面」代替「禁止伪三维」。否定指令遵循率低，还可能把被禁止的东西带进画面。
- 不写工程或流程词（原生、可编辑、裁切、PowerPoint、校核、提示词、页尾交付），也不写段落编号或标题符号，避免被画进图里。
- 不写上屏文字原文、数字、引文和来源。上屏文字由系统根据确认稿注入，模型自行添加的字会在可编辑重建时被丢弃，但会破坏成图。

## 依据

- OpenAI 图像提示建议按「用途 → 场景 → 主体 → 细节与文字 → 风格 → 约束」顺序书写，上屏文字放进引号并说明位置与层级，文字较密时使用高质量档。
- Google Gemini 图像提示建议描述场景而非堆关键词，说明意图，用正向语义描述代替否定词，复杂画面分步搭建，用参考图保持一致；画幅由接口参数设定。
