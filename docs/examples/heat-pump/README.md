# 低温空气源热泵现场监测

这套科研汇报样例沿着一条实际工作线展开。从室外环境、机组和水侧布点开始，再说明怎样整理记录、回查事件和对照不同工况。共 5 页，16:9。

[下载可编辑 PowerPoint](heat-pump-monitoring.pptx?raw=1) · [返回项目首页](../../../README.md)

![实际 PPTX 渲染的四张内容页：监测布点、预处理、事件复核、工况对照](overview.webp?v=2)

| 页 | 内容 |
| --- | --- |
| 1 | 界定监测对象为空气－水热泵供暖系统，列出五类核心监测量。 |
| 2 | 在热泵与建筑剖面上标出三组测点，区分供水、回水和计量口径。 |
| 3 | 把原始记录整理成可回溯的工况时窗，单独标记表计复位和数据缺口。 |
| 4 | 对照开窗换气和供热暂降，列出同一时窗内可核对的记录。 |
| 5 | 用两张原生柱图对照供回水温差和平均电功率。 |

演示稿使用 FrameDeck 的原生场景渲染器。文字、测点标签、供回水箭头和流程连线可在 PowerPoint 中修改，两幅柱图各有内嵌数据表。设备图和房间剖面为 AI 生成的示意素材，可独立替换。柱值是合成区间均值，仅用于展示读图方法。
